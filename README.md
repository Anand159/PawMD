## Project Description
Overview:
PawMD is a sleek, emotionally engaging landing page designed for a veterinary clinic, pet health service, or animal care startup. It aims to build trust with pet owners by highlighting services, team expertise, and accessible care options in a visually warm and modern layout.

## Objective for UI Developer:
Develop a responsive, high-performance landing page based on the provided Figma file. The UI should align pixel-perfectly with the design, be mobile-friendly, and optimized for conversion, with smooth scroll effects and subtle animations where appropriate.
